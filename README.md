# Ghislieri Services

Telegram bot for the students of Collegio Ghislieri: canteen bookings, college calendar, printing, content submissions and notifications.

```sh
uv sync
cp deploy/ghislieri.env.example .env   # set GS_ENV=dev and the test bot token
uv run ghislieri
```

Documentation for maintainers is in [docs/](docs/README.md).
